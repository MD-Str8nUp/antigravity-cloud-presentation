# 02: Component Catalog, Parametric Search & Multi-Lot Stock Adjustments

**What to build:** End-to-end **Component** and **Stock Lot** cataloging across the nine built-in audio electronics categories (plus `Other / Custom`), featuring shorthand specification entry with verbatim `raw_spec_text` preservation, debounced HTMX parametric search (`delay:150ms`) with a live `spec_parser` interpretation badge, dynamic category `specs_json` filters, recursive **Storage Location** subtree filtering, **Available Stock** vs. total on-hand display, inline `− / qty / +` steppers for single-lot **Components**, and the right-hand Inspector Drawer for multi-lot adjustments and 1-click **"Merge Duplicate Stock Lots"**.

**Blocked by:** 01: Workspace Foundation, Spec Parser & Hierarchical Storage Locations

**Status:** resolved

- [x] A builder can create and edit **Components** across all 9 built-in categories (`Resistors`, `Capacitors`, `Semiconductors — Discrete`, `Integrated Circuits (ICs)`, `Potentiometers & Encoders`, `Switches, Jacks & Connectors`, `Inductors, Transformers & Magnetics`, `Enclosures, Knobs & Mechanical Hardware`, `Modules & Sub-Assemblies`, plus `Other / Custom`) with subtype, `package_or_mounting`, `raw_spec_text`, normalized numeric values (`resistance_ohms`, `capacitance_pf`, `inductance_uh`, `voltage_rating_volts`), `canonical_value_display`, validated category-specific `specs_json` attributes, `low_stock_threshold`, `datasheet_url`, and notes.
- [x] Typing shorthand queries (`4k7`, `4700R`, `0.047uF`, `47n`, `100kB`, `TL072`) into the debounced catalog search bar (`delay:150ms`) filters matching **Components** by normalized electrical value or text and renders a live `spec_parser` interpretation badge right beside the search input showing how the query was parsed.
- [x] Selecting a **Component** category dynamically reveals and applies category-specific `json_extract(specs_json, ...)` filter controls (such as tolerance/wattage/composition for Resistors, dielectric/voltage/polarized/lead spacing for Capacitors, taper/body size/shaft type for Potentiometers), and selecting a **Storage Location** filters **Components** stored in that container or any of its nested child **Storage Locations**.
- [x] Every **Component** row displays both `canonical_value_display` and verbatim `raw_spec_text`, its **Storage Location** breadcrumb(s), and an **Available Stock** badge showing `Available / Total On Hand` alongside a low-stock warning when stock is at or below `low_stock_threshold`.
- [x] When a **Component** has a single **Stock Lot**, an inline `− / qty / +` stepper is rendered directly inside the catalog table row and updates that row via HTMX without a page reload.
- [x] When a **Component** has multiple **Stock Lots** across different **Storage Locations**, clicking the row opens the right-hand Inspector Drawer (`#inspector`) listing every lot with its own `− / qty / +` stepper, lot-level supplier/part number/notes, and a 1-click **"Merge Duplicate Stock Lots"** action (as well as automatic lot merging whenever stock is moved or added into a **Storage Location** that already holds a lot for that **Component**).
- [x] Integration tests against `:memory:` Turso verify **Component** creation, normalized value + `specs_json` parametric queries, recursive **Storage Location** subtree filtering, single-lot and multi-lot delta adjustments, and automatic/manual **Stock Lot** merging.
