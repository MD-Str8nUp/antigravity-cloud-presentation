# 06: Two-Step Staged CSV & Clipboard Imports for Components and BOMs

**What to build:** End-to-end two-step staged CSV upload and clipboard paste import workflows for both **Components**/**Stock Lots** (with supplier column-mapping presets for Mouser, DigiKey, Tayda, and LCSC, user-saved presets, and interactive `Exact Match` / `Near / Ambiguous Match` / `No Match` reconciliation before atomic commit) and **Kit Build** **BOMs** (supporting `Append` and `Replace Unallocated Lines` modes, automatic category inference from reference designator prefixes, and the **"Automatic Designator Grouping"** toggle that combines identical-spec single-designator rows).

**Blocked by:** 03: Kit Builds, BOM Line Auto-Matching & 5-State Stock Fulfillment

**Status:** resolved

- [x] A builder can upload a CSV file or paste tabular text to stage a **Component & Stock Lot** import batch, select a default target **Storage Location** and optional default `Supplier`, and map columns using auto-detected supplier presets (`Mouser`, `DigiKey`, `Tayda`, `LCSC`) or saved custom mapping presets.
- [x] Before writing to the catalog, the **Component** import staging preview parses every row with `spec_parser` and classifies each row as `Exact Match` (matched by `supplier + supplier_part_no` or normalized `category` + value + package + key attributes; defaulting to adding/incrementing a **Stock Lot** on the existing **Component**), `Near / Ambiguous Match` (prompting 1-click user selection between existing candidate **Components** or creating a new one), or `No Match` (defaulting to creating a new **Component** + initial **Stock Lot**, and auto-creating any new **Storage Location** in the path when requested), then commits the reconciled batch atomically.
- [x] A builder can upload a CSV file or paste tabular text to stage a **Kit Build** **BOM** import (in either `Append` or `Replace Unallocated Lines` mode), automatically inferring `category` from `reference_designators` prefixes (`R`, `C`, `D`/`Q`, `U`/`IC`, `RV`/`VR`, `SW`/`J`, `L`/`T`) when a category column is unmapped.
- [x] When the **"Automatic Designator Grouping"** toggle (enabled by default) is active during **BOM** import staging, separate rows sharing an identical normalized `Category + Spec + Package` are merged into a single staged **BOM Line** with summed `quantity_required` and merged `reference_designators` (e.g., `R1, R2, R5`), and committing the staged batch links unambiguous single-match **Components** automatically.
- [x] Integration tests against `:memory:` Turso verify **Component** import staging, `Exact Match` / `Near / Ambiguous Match` / `No Match` classification, user overrides, and atomic commit into **Components** and **Stock Lots**, as well as **BOM** import staging with designator category inference, identical-spec designator grouping, and `Append` vs. `Replace Unallocated Lines` commits.
